# Physics-Gen Daily Reports

> Auto-generated by the Pulsar Physics-Gen pipeline (`scripts/pulsar/`).
>
> 每個 weekday 一份 markdown，含當天 arxiv cs.CV / cs.LG / cs.GR / cs.RO / cs.AI / physics.flu-dyn /
> cond-mat.soft 過濾後的 LLM 評級結果。

## 文件命名

```
YYYY-MM-DD.md
```

## 結構

```markdown
# Physics-Gen Daily — YYYY-MM-DD

> Pulsar pipeline auto-generated. N papers rated; ⚡ X · 🔧 Y · 📖 Z

## ⚡ Load-bearing (X)
- [Title](link) (arxiv_id · category) ⭐
  - reason · [output:… · injection:… · control:…]

## 🔧 Engineering (Y)
...

## 📖 Reference (Z)
...
```

5 軸 tag 取自 ontology v2（`cheat-sheet/ontology.md`）：output / **injection ★ USP** / control /
temporal / domain。

## 評級語義

- ⚡ **影響重大**（新 SOTA / 範式 / Cosmos-tier release）
- 🔧 **工程實作有料**（reproducible，改進明確）
- 📖 **值得知道**（背景知識 / 綜述 / 重要 baseline）
- ❌ **不收**（無物理 / 無 controllability / 純 NLP-LLM）

## Retention

90 天自動 prune（`scripts/pulsar/post.py` 內建）。

## 整合方式

- TG：不接（同 Spatial 決定，整合走 git）。
- Handbook git：每份 daily markdown commit 進 git（GitHub Actions auto-commit）。
- Mintlify：經 [`reports/overview.md`](../overview.md) landing page 串接（日檔不進側欄逐頁，避免數百筆日期條目）。

詳見 [`scripts/pulsar/README.md`](../../scripts/pulsar/README.md) 與
[`docs/pulsar-integration.md`](../../docs/pulsar-integration.md)。
