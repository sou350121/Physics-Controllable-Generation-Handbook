# Physics-Controllable Generation 週報（2026-10-23 – 10-28）

本週樣本：⚡ 10 篇、🔧 112 篇。方法層的增量大多落在工程帶，但**範式訊號集中在「世界模型的內部結構」而非「生成品質」**——這是本週最值得記錄的轉向。

## 本週主軸

**1. 動力學外包：生成器退回渲染器，物理交給顯式狀態層。**
DeXplicit 先以度量 3D 動力學網路預測物件運動與形變、再由視頻渲染器補外觀（moved-point error 降 27–40%、兩步因果 57x 加速）；E0.5 更徹底，直接以 3D foundation 為主幹顯式預測未來 3D 狀態與動作；UniWorld 用滾動深度潛狀態做長程續寫、BoxWorld 讓規則引擎管動力學、生成器只渲染狀態流。這條線的共同主張是：**物理不該從像素統計裡隱含出現，該從一個可量測、可干預的狀態層出現**。

**2. 可控性主戰場從訓練期移到推理期。**
Rollback 把世界模型從單向模擬器改成可回溯分支的反事實引擎，並用真實轉移經 LoRA 做 test-time 物理校正；PhysibleMDM 以 Sep-CMA-ES 在黑箱噪聲上做推理期可行性優化；WorldForge V2 的 warped-reference guidance 與 Best-of-N 的 fail-gated 選擇器同理。判準很清楚：**物理約束以「事後修正／事後挑選」的形式進入，便宜、免重訓，但不可證明**。

**3. 評測基建先於方法成熟，而且驗收結果對現有方法不利。**
WMEval 用 Unity 物理模擬器當 state-level oracle、RoboWorM 用運動學樹做免 VLM 的部署感知審計（29k rollout）、ScIntBench 把「靜態合理」與「交互可靠」分離、WorldEcho/WorldSync 專測動作跟隨性、ACWM-RM 提供無參考獎勵。本週的方法論文多數仍在補這些基準揭露的洞。

## 意外信號

**① 世界模型的「世界性」被自家基準大幅下修。** ScIntBench 顯示 12 個 SOTA 3D 場景生成系統在操作任務上最佳僅 36.92%，且靜態物理合理**不轉移**到動態交互；WorldEcho 指 action-conditioned 世界模型在 off-expert 動作下跟隨性明顯不足；「What Does World Modeling Actually Improve」用受控消融給出增益邊界。合起來是一個反共識：**感知相似度（FVD/PSNR）與物理可控性之間的相關性，比社群假設的弱得多**。

**② 規模不再是 world-action model 的護城河。** GAWM 以 <100M 參數在 RoboTwin 2.0 超越十億級 WAM；OSWAM 做單步動作生成、Euler 單步 flow matching 實證可匹配多步、TurboWAM 專攻推理加速。這把瓶頸從容量改指向**表徵與條件化設計**，與主軸 1 相互支持。

**③ 目標函數被重定義：前向精度不再是終點。** Posterior-First 主張從單場觀測推「下游任務需要的後驗」而非更準的 rollout；Rollback 要的是可分支回溯而非單軌預測；Identifiability 那篇首次給出 hybrid-DGM 物理參數可識別性的理論條件——這其實是給整個 physics-conditioned 生成畫了上限：**多數情況下物理參數可能根本無法從生成分佈中唯一恢復**，而 meta-learning 只是其中一條繞路。

## 五軸熱度

**output** — pixel/latent-video 仍是大宗（粗計約四成），第二極是 3D（asset / scene / gaussian / mesh）。真正的位移不在佔比而在身份：**3D 從「輸出格式」升格為「潛在狀態」**（E0.5、DeXplicit、UniWorld），latent 則被當成效率輸出（GAWM、TrackTok）。

**injection（USP）** — 本週呈現**雙峰**：architecture-bias（結構性歸納偏置）與 sim-in-loop（AgentDreamer 的 MPM 反優化、DiffDreamer、SceneAgent、WorldMirror）各據一半，⚡ 層幾乎全落在這兩格。hard-constraint 條數確實上升——cochain-frame 的 Hodge 硬恆等式與 PSD 算子、Explicit Frictional Contact 的閉式 Coulomb 錐把 μ 變成推理期旋鈕、GeoDiv KAN 的 streamfunction 硬約束、DuoPIC 的守恆構造、CoCarry 的接觸支撐約束——但**全部落在 🔧 且集中在特定 domain（流體、聲學、醫學、軟機器人）**，沒有一篇進入 world-model 主幹；data-only 也未消失（PhyEvolve 明說物理只透過語言條件間接進入）。另有一個新注入位置值得記：**採樣／噪聲幾何**（SyncVid 的 canonical 3D 噪聲採樣、TrajCFG 的 token-wise CFG、World-in-Context 的 IT-RoPE、UniWorld 的噪聲對齊續寫）——注入從 loss 移到了 noise/sampling 空間。

判斷：**注入強度光譜這週是「中段變厚、兩端未動」**。sim-in-loop 仍是唯一同時餵到生成與控制的注入方式，且它正在被工程化成 pipeline（FluxVLA、Zero-HLM、AuRA、AffordSim）而非方法創新。

**control** — 相機／軌跡控制明顯飽和（WorldForge V2、WorldCast、Distilling Dense Trajectory Teachers、Memorize When Needed、Hy-Nomas、OmniShowcase）。新興的控制面有兩個：**物理參數作為推理期旋鈕**（摩擦 μ、可識別參數、physics-parameter conditioning），以及**token 化統一控制**（World-in-Context 把 view/action/camera 收進同一 in-context token、UniAction 統一異質動作）。

**temporal** — 只有一個戰場：長程 rollout。共同敵人是 drift / exposure-bias / 拼接誤差，解法從「記憶模組」轉向**持久狀態 + 分段滾動 + rollout distillation**（UniWorld 滾動深度潛狀態、Past as State 的 persistent-state blockwise、BoxWorld 的 rollout distillation、Vorch-Director 的噪聲級別殘差注入）。

**domain** — robotics/manipulation 壓倒性（WAM/VLA/生成式機器人數據）；PDE／流體／氣候為第二極。值得注意的是**非典型物理域在擴張**：聲學、電離層 TEC、野火、地下流、人工生命（FlockWorld）、遊戲渲染。這些正是 hard-constraint 真正落地的地點——反過來證明主幹模型還缺硬約束。

## 可證偽觀察清單

1. **state-level 指標的出現率。** 下週 ⚡ 清單中應至少 1 篇以 explicit 3D／物理狀態為輸出，並報告 state error（moved-point、軌跡、接觸）而非僅 FVD/PSNR。若下週 ⚡ 仍是 pixel-video + 感知指標的全集，則主軸 1 應降級為「工程帶現象」。
2. **hard-constraint 是否溢入主幹。** 檢查下週是否出現以守恆律／Hodge 恆等式／接觸錐作為**生成主幹硬約束**的 ⚡ 論文。若 hard-constraint 仍 100% 落在 🔧 且 domain-specific，「注入強度上移」不成立，USP 應改記為「架構偏置停滯、硬約束原地踏步」。
3. **評測是否轉成訓練信號。** 下週應出現 ≥1 篇把 action-following 或 interaction plausibility **直接寫成對齊損失／訓練目標**（WorldSync 譜系擴散）。若只新增更多 benchmark 而無對應訓練方法，則「評測已反噬成訓練驅動力」證偽。
4. **小模型／單步是否維持。** 下週若再出現 <200M 或單步推理的 WAM 在標準 bench 上勝過大模型（GAWM / OSWAM / Euler 譜系），則「規模護城河失效」成立；若 SOTA 全數回到大模型多步採樣，此判斷作廢。
